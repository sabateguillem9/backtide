# Logos

- `backtide-wordmark.svg`: the wordmark outlined from Jost Medium (-0.045em), with the round dot of the i. Ink `#0b0b0b` (`ink`). Use it where the font cannot load: emails, slides, social images.
- `backtide-wordmark-white.svg`: the same in white (`paper` of the dark theme), for ink grounds.
- `backtide-mark.svg`: the dot alone, ink. Favicon, avatars, app icon.
- `backtide-mark-white.svg`: the dot in white, for ink grounds.

Clear space: at least the x-height of the wordmark on every side. Never stretch, outline, shadow, recolor or set in capitals.
