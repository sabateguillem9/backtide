Layers

Inside the box

Four containers on Linux. The agent lives in one; the other three watch it from outside.

  1. backtide

    The black box, the snapshots, the rules and the web, with more privileges than the agent, never fewer.

  2. sensor

    Tetragon (eBPF): every command and connection, seen from the kernel instead of told by the agent.

  3. proxy

    mitmproxy, the agent's only way out. It records every request before it leaves and holds what writes.

  4. agent

    OpenClaw or Claude Code, with no root, no capabilities and no way out except the proxy.
