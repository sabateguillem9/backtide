Design system · v2

backtide

Ivory paper, ink type and one touch of clay. Lora for headlines, DM Sans for text, small drawings by a steady hand, and motion that arrives once and settles. The one source for the public site and the product web.

See the components Read the brand book

Colour

Two themes. Light, on ivory, is the default; dark is charcoal with clay, for whoever prefers it. Each swatch shows both, and the lowest contrast it reaches on any surface it may sit on.

Layers

Inside the box

Four containers on Linux. The agent lives in one; the other three watch it from outside.

  1. backtide

    The black box, the snapshots, the rules and the web, with more privileges than the agent, never fewer.

  2. sensor

    Tetragon (eBPF): every command and connection, seen from the kernel instead of told by the agent.

  3. proxy

    mitmproxy, the agent's only way out. It records every request before it leaves and holds what writes.

  4. agent

    OpenClaw or Claude Code, with no root, no capabilities and no way out except the proxy.
