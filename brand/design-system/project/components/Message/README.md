# Message

A headline with the one line that explains it. On the landing page, each crest of the tide carries one.

- Props: `title` (the headline, in `headline`), `children` (the line under it, in `body` and `ink-muted`), `status` (an optional `Status` line under it), `align` `center` (default) or `start`.
- On the crests, every message carries its `Status`, so people see what is built and what comes next.
- Keep the headline under eight words and the line under fifteen. One message per screen.
