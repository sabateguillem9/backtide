# Document

A document page (privacy policy, legal notice, docs): the small wordmark as the home link, a `title`, the date, sections and the ruled footer, in one `size-measure` column.

- Props: `title`, `updated`, `homeHref`, `sections` ([{ heading, body }]) or free `children`, and `footer` (usually a ruled `LegalFooter`).
- Body text is `body-long` in `ink-soft`. Keep it plain: no cards, no icons, no images.
