# Mark

The dot: a perfect ink circle and the brand mark.

- It is the dot of the i, the favicon, the avatar and, as `DotButton`, the call to action.
- Props: `size` in px (default 16), `tone`, and `label` when it stands for backtide on its own (otherwise it is decorative and hidden from screen readers).
- Use one dot per view. A second dot makes it decoration.
