# Components

One folder per component, each with its README (what, when, variants, states, accessibility, markup, what it replaces in the product web). All the CSS is in `bundle.css` and uses only tokens; `bundle.js` animates the language indicator and lights Inside the box.

From the C2 proposal: `Wordmark`, `Button`, `Link`, `Status`, `IndexRow`, `SectionHeader`, `Layers`, `LogbookEntry`, `LegalFooter`, `LanguageSwitch`, `Document`.

For the product web (phase 3): `Notice`, `HoldCard`, `Table`, `Field`, `Badge`, `EmptyState`, `Tabs` (with Nav and Chips), `AgentTag`, `Card`, `Disclosure`, `Timeline`.

See them all, in their states and in both themes, on `../index.html`.
