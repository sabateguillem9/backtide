# TextField

A field: a label in `small`, the text in `input` (22px), and one `stroke-hairline` under it. Never a box.

- Props: `id` (required), `label`, `name`, `type`, `placeholder` (in `placeholder`), `autoComplete`, `inputMode`, `value`/`defaultValue`/`onChange`, `required`, and `action` to put a control at the end of the line.
- Always give a visible label; the placeholder is only an example.
